# HeroUI Theme Studio

Unofficial theme generator for HeroUI v3.

- Keep the balanced workspace across Web views. Put the editor beside the preview on wide screens and above it on narrow screens. Use default HeroUI Tabs for platform and preview navigation, with the header tabs centered at the same position across Web views. Native keeps its own simulator area.
- Group the semantic colors in two columns with CSS variable names and swatches. Show the current color and a reset action. An untouched or reset control follows the installed HeroUI theme, including links to other variables.
- Put radii, border widths and typography together. Keep editing scoped to the active mode. Place Web and Native at the top of the editor toolbar, above the swatch-based preset picker, Light/Dark, reset and import.
- Use HeroUI component variants, typography, and semantic surfaces. Use Tailwind utilities for layout and spacing. Keep focus visible, respect reduced motion, and fit the website demo to its own container when the assistant is open.
- Keep the assistant on the right and let users review a proposal before applying it. Open Export CSS from the header in an inset, right-aligned modal with copy and download actions.
